# BVG // NIGHT SHIFT — cyberpunk-концепт карьерного сайта

Style: cyberpunk (неон BVG-жёлтый + маджента/циан на почти чёрном). Неофициальный концепт.

## Шаг 1 — Хиро + табло вакансий
- [x] Vite + Three.js проект, шрифты, токены
- [x] WebGL-туннель U-Bahn: каркасные кольца, огни линий U1–U9, частицы пыли, рельсы
- [x] Пост-обработка: bloom, хроматическая аберрация, сканлайны, глитч-импульс
- [x] Курсор → камера (с пружиной), скролл → скорость поезда
- [x] HUD: навигация, заголовок с глитчем, CTA, спидометр, часы
- [x] Табло «Abfahrt»: вакансии, перещёлкивающиеся буквы, фильтры
- [x] Reduced motion + фолбэк без WebGL
- [x] Проверка: десктоп 1440, мобайл 375, консоль без ошибок

## Шаг 2 (позже)
- [x] Bereiche: 4 HUD-карточки, наклон + свечение за курсором
- [x] Ausbildung: маршрут-схема, заполняется скроллом, остановки загораются
- [x] Benefits: голографические билеты с перфорацией
- [x] Финал «Zurückbleiben? Bitte nicht.» + варп-разгон туннеля
- [x] Проверка: 1440 и 375, без ошибок и горизонтального скролла

## Шаг 3 — «Wir sind 16.000» (паттерн толпы BVG)
- [x] Ночная версия паттерна + фонарик с дневными цветами
- [x] Скан силуэта (flood fill по исходным пикселям), неоновый контур, ID-плашка
- [x] Линия сканирования, счётчик «Erkannt», авто-режим на тач-устройствах
- [x] Проверка: 1440 и 375; починил плашку, уезжавшую за край на мобильном

## Review (шаг 1)
- Vite + Three.js, без фреймворка. Запуск: `npm run dev` → http://localhost:5190
- Проверено: 1440 и 375, консоль без ошибок, табло рендерит 10 строк, фильтры, без горизонтального скролла.
